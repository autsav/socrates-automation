# Attention Magnet — Design Spec

**Date:** 2026-07-19
**Status:** Approved (Approach A "Cinematic Performance Overhaul" + C-lite `punch` arc; AI-video Approach B deferred)
**Goal:** Rebuild the four production layers the user diagnosed as unengaging — voice, visuals, pacing, writing — so reels read as "produced," not "slop template," and generate cheap hook-variant tests.

## Research basis (2026-07-19 deep dive, 3-agent sweep)

- The current format (quote text + scenic stock + flat TTS) is the definitional slop template: default output of every no-code tool, pattern-matched and swiped in <1s, actively suppressed by Instagram's 2026 originality scoring.
- Winning stoic accounts: emotionally charged human footage + deep directed VO + kinetic captions + cuts synced to speech stress, 15–45s.
- Measured levers: visual event in first 500ms (Meta guidance); captions +15–40% completion; varied prosody ≈ +25% retention vs flat; lower-pitch AI voice narrows the AI-vs-human gap (peer-reviewed); pattern interrupt every 3–5s; silence as the strongest audio interrupt; loop/rewatch = highest-confidence ranking signal.
- Breakouts land on variant #11–47 of a tuned system → volume of tested hook variants matters (C-lite).
- #1 produced-vs-slop marker: a visible editorial layer / persona POV.

## Locked decisions

| Decision | Choice |
|---|---|
| Scope | A (voice + footage + grade/density + persona) + C-lite (`punch` arc) |
| Deferred | B: AI-generated cinematic video; movie/anime clips (licensing); avatars; voice cloning |
| Fallback contract | Every new layer is best-effort; current behavior is the fallback |
| Measurement | Existing loop: sends-per-reach per arc via post_metrics + bandit |

## 1. Directed voice performance

**New:** `src/audio/voice_director.py`
- `delivery_profile(scene: str, chapter_index: int | None = None) -> dict` — maps scene → ElevenLabs `voice_settings` overrides + text preprocessing:
  - `hook`: low stability (expressive), high style — intense fast attack.
  - `bridge` chapters: stability decreasing across chapters (urgency builds); `<break time="0.4s"/>` inserted at chapter turns (sentence-group boundaries).
  - `quote`: highest gravitas — high stability, low style, preceded by an engineered **silence drop**: 0.8s of near-silence before quote VO starts (implemented in the scene timeline, not the audio file).
  - `cta`: direct, default settings.
- `apply_gravitas(path: Path) -> None` — ffmpeg pitch-down ~5% (asetrate/atempo pair) applied to the quote VO only.

**Modify:** `src/audio/elevenlabs_engine.py` — `generate_scene_voiceover(..., settings=None)` already accepts overrides; pipeline passes `delivery_profile(...)` per scene.

**Sound design (Remotion + bridge-file):** extend the existing synthesized SFX set with `riser` (into quote) and `sub_impact` (on the twist/emphasis beat). Music duck goes to near-zero during the pre-quote silence drop.

## 2. Dramatic footage engine

**Modify:** `src/visual/stock_footage.py`
- `DRAMATIC_POOLS: dict[mood, list[str]]` — human-struggle/motion queries ("boxer wrapping hands dark gym", "man walking into storm rain", "runner collapsing exhausted track", "hands gripping climbing rope", "silhouette training night city"...). ≥6 per mood.
- `fetch_reel_clips(mood, topic_query, n=4) -> list[Path]` — fetches up to n distinct clips: topic_query first (if it passes the human-motion heuristic), then dramatic-pool picks; dedupe by Pexels video id; falls back to the single-clip path on any failure.
- Human-motion constraint on story_writer's `topic_query`: prompt instructs "a HUMAN doing something physical" for topic_query; `_is_scenery(query)` heuristic swaps pure-scenery queries for a dramatic-pool pick.

**Pipeline:** `_run_pov_reel` passes the clip list into the bridge file (`backgrounds: [names]` + per-clip durations). Single-background payload stays byte-compatible when only one clip exists.

## 3. Cinematic grade + edit density (Remotion)

- **`BackgroundReel.tsx` (new)**: renders a sequence of background clips; cut points = scene boundaries + (within long bridge scenes) VO word-stress timestamps (from existing `wordTimes`, stress = words with times gap > threshold or chunk starts) so cuts land on speech emphasis every ~3–5s. Falls back to `BackgroundPhoto` behavior for one clip.
- **`FilmGrade.tsx` (new)**: letterbox bars (10% top/bottom), animated grain overlay (SVG turbulence, low opacity), per-mood duotone via existing ColorGrade extension.
- **Punch-ins:** extend `cameraZoom` — 4–8% scale snap on each beat frame (already computed), speed-ramp (scale ease-in) across the 12 frames into the quote scene.
- **500ms rule:** hook text full-visible at frame 0 (exists) + scale pop 1.0→1.04→1.0 over frames 0–8 + background clip chosen to open with motion.

## 4. C-lite: `punch` arc

- 7–15s format: Hook (one brutal line, ≤10 words) → Quote → send-CTA. No bridge.
- Generated by story_writer in a new `punch` mode (schema unchanged; `beat_reframe` empty allowed for this mode; validate_story gets a `mode` param: punch → total 25–60 words, no reframe requirement).
- Rotation: `punch` replaces one `classic` and one `question` slot in both rotation tuples (~20%); recorded in `posts.arc` as `punch` — the bandit measures it like any arc.

## 5. Persona layer

- story_writer `_PREFIX` + copywriter draft prompt gain: first-person mentor POV ("I", direct address "you", no third-person narrator distance) + a consistent caption sign-off line: `— The Stoic Reset` (matches the funnel product).
- No visual persona (no avatar/face) — voice + POV + sign-off only.

## Error handling

Never-crash contract everywhere:
- voice_director failure → default settings (current behavior).
- Multi-clip fetch failure → single clip → gradient background (existing chain).
- Grade/grain/letterbox are pure Remotion visuals — no runtime failure path beyond render, which already falls back to the ffmpeg generator.
- punch-mode validation failure → `_fallback_arc` as today.

## Testing

- Unit: delivery_profile mapping per scene; gravitas ffmpeg args; DRAMATIC_POOLS all pass `is_unsafe`+scenery heuristic; fetch_reel_clips dedupe + fallback; punch-mode validate_story budgets; rotation contains `punch` at expected slots.
- `npx tsc --noEmit` clean.
- Dry-run renders: one story (multi-clip cuts visible at stress points; letterbox + grain in frames; silence drop before quote audible), one punch (≤15s).
- Live acceptance: one post, Graph read-back + first comment.

## Not in scope

AI-generated video (B), movie/anime clips, avatars, voice cloning, bio/profile changes, Trial Reels.
